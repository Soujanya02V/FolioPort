# Achievements & Recognition Images

Place your achievement, award, certificate, and recognition images in this folder.

## Image Files Mapping:
You can add your images here and reference them in `src/data/portfolio.ts`.

Example filenames:
- `internship.png` / `internship.jpg`
- `project.png` / `project.jpg`
- `hackathon-organizer.png`
- `hackathon-participant.png`
- `open-source.png`
- `freelance.png`
- `leetcode.png`
- `leadership.png`

### How to customize:
1. Copy your image files into `public/images/achievements/`.
2. Update the `image` field for each item in `src/data/portfolio.ts`.
